# Aurelle — Jewellery Website Starter

A responsive, multi-page luxury jewellery storefront prototype made with plain HTML, CSS and JavaScript. It is inspired by premium jewellery editorial design, not affiliated with or copied from Tanishq.

## Run locally
1. Extract the ZIP.
2. Open the `verve-jewellery-v2` folder in VS Code.
3. Install/use the **Live Server** extension if available.
4. Right-click `index.html` → **Open with Live Server**.
5. If you do not have Live Server, open `index.html` directly in your browser. Some browser restrictions can affect local navigation or assets.

## Pages
- `index.html` — homepage, campaign, scroll-linked editorial animation, collections, featured products
- `pages/collections.html` — category filters, search query and price sorting
- `pages/product.html` — product detail template
- `pages/about.html` — brand story placeholder
- `pages/contact.html` — showroom enquiry form prototype

## Important before launch
- **Aurelle is a placeholder brand name.** Replace it with the client's approved brand name and logo.
- Product names, prices, category, images and descriptions in `script.js` are demo content.
- Product imagery currently loads from Unsplash and requires an internet connection. Replace with licensed/client-approved images for production.
- Cart state is only stored in browser local storage; there is no real checkout or payment.
- Newsletter and contact forms are demo interactions. Connect them to Shopify, a CRM or a form/email service before publishing.
- Confirm all material descriptions, gold purity, diamond specifications, hallmarking, taxes, shipping, returns and warranty information with the client.
- This is a front-end prototype. Shopify product/catalog/cart/checkout integration comes after the design is approved.
